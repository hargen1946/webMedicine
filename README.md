# ブラウザ版 お薬手帳

Android版の主要機能をブラウザ向けに移植したPWAです。サーバーやアカウントは不要で、記録は利用中のブラウザの `localStorage` に保存されます。

紙の院外処方箋QR（JAHIS9/JAHIS10等）と、電子版お薬手帳データ（JAHISTC等）の両形式を判定して解析します。QR解析にはプロジェクト内に同梱した ZXing-WASM 2.2.4 を使用するため、外部CDNには依存しません。

## 起動方法

カメラを使わず確認するだけなら `index.html` を開けます。カメラ読取とPWAインストールには、HTTPSで公開するか、開発中はlocalhostで配信してください。

```powershell
cd C:\path\to\medicine-notebook-web
python -m http.server 8080
```

その後、PCでは `http://localhost:8080` を開きます。スマートフォンでカメラを利用する本番運用では、静的ホスティングサービスへフォルダ一式を公開してください。

## データについて

- 保存先はブラウザ内です。別のブラウザや端末とは自動同期されません。
- 記録はスマートフォン本体のセキュリティ機能で保護されます。より安全に使うため、端末には画面ロックを設定してください。
- ブラウザのデータを消すと記録も消えます。定期的に「データ出力」からJSONを保存してください。
- 「復元」でJSONバックアップを現在の記録へ統合できます。
- QRカメラ読取に非対応のブラウザでは、QR画像の選択を利用できます。
- カメラ読取は全画面と中央領域を交互に解析し、Shift_JISの日本語を復元します。
- 解析はWeb Workerで行うため、読み取り中も画面が固まりにくい構成です。

## 安全性について

- Content Security Policyにより、スクリプトと通信先をこのアプリ自身に限定しています。
- 復元するバックアップは、最大5MB・最大1,000件です。項目の種類、文字数、薬と用法の件数を保存前に検査します。
- バックアップに不正な項目がある場合は、途中まで復元せず、ファイル全体を取り込みません。

## 簡易テスト

Node.jsが利用できる場合は、次のコマンドで両方のJAHIS形式の解析テストを実行できます。

```powershell
node .\tests\parser.test.cjs
```
